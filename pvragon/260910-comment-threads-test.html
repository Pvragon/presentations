Comment Threads Test

This page is the proving ground for prez comment threads: highlight any passage, click Comment, and a thread is pinned to that text. No account is needed. Your name and color are remembered on this device for every prgn.ai site, the same way play.prgn.ai does it.

How to leave a test comment

  1. Highlight a run of text anywhere on the page. A small Comment button appears above it.
  2. Click it, type your comment, and post. The first time, you will be asked for a name and a color.
  3. Open the Comments button in the top-right header to see every thread on the page, reply, or resolve.

Things to comment on

A comment can pin to a point on the page or to a highlighted passage. Try one of each. This paragraph exists to be highlighted. It has no other purpose, which makes it the ideal target for a test comment, because nothing depends on it and nothing will break when it changes later.

The second paragraph is here so that a comment thread can be tied to a different element. When the page is redeployed with new text, we want to know whether the thread stays attached, floats to the top, or disappears. That behaviour decides whether prez comments can be trusted across revisions.
